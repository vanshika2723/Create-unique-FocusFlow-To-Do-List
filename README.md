# ✦ FocusFlow - Simple To-Do List

A modern and interactive **In-Memory To-Do List** built using **HTML, CSS, and JavaScript**.

FocusFlow helps users add, complete, and delete daily tasks through a clean productivity-focused interface. Tasks are managed using a JavaScript array and are not stored permanently.

## 🚀 Live Demo
https://vanshika2723.github.io/Create-unique-FocusFlow-To-Do-List/

## ✨ Features

- ➕ Add new tasks
- ⌨️ Add tasks using the Enter key
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📊 Real-time task counter
- 📈 Dynamic progress percentage
- 🎨 Modern glassmorphism UI
- 🌌 Premium dark gradient design
- 📱 Fully responsive layout
- ⚡ Instant DOM updates
- 🔄 In-memory task management
- 🛡️ HTML escaping for safer task rendering
- 🖱️ Event delegation for task actions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- JavaScript Arrays
- Event Listeners
- Event Delegation
